# kazvocab

## Зачем

Списки слов легко прочитать и так же легко забыть. Работает другое: возвращаться
к слову ровно тогда, когда оно вот-вот забудется.

`kazvocab` раскладывает карточки по коробкам. Ответил верно — слово уходит в
коробку выше и вернётся не завтра, а через три дня, потом через неделю.
Ошибся — падает в начало и спрашивается снова сегодня. Так время тратится на
то, что даётся тяжело, а не на уже выученное.

## Установка

```bash
git clone https://github.com/Aslanzhamenkenov/kazvocab.git
cd kazvocab
```

Зависимостей нет — только стандартная библиотека Python 3.10+.

## Как пользоваться

```bash
python -m kazvocab.cli quiz                      # разбор на сегодня
python -m kazvocab.cli quiz --topic numbers      # только числительные
python -m kazvocab.cli quiz --direction ru->kk   # с русского на казахский
python -m kazvocab.cli quiz --limit 10           # короткий подход

python -m kazvocab.cli topics                    # список тем
python -m kazvocab.cli status                    # что уже выучено
python -m kazvocab.cli reset                     # начать заново
```

Как выглядит опрос:

```
5 карточек · направление kk->ru

[1/5]
  жаңбыр  →  дождь
  ✓ верно

[2/5]
  көл  →  река
  ✗ неверно — правильный ответ: озеро

результат: 4 из 5 правильно
прогресс сохранён: ~/.kazvocab/progress.json
```

## Как устроено повторение

| Коробка | Следующий показ |
|--------:|-----------------|
| 0 | сегодня |
| 1 | через 1 день |
| 2 | через 3 дня |
| 3 | через 7 дней |
| 4 | через 16 дней |
| 5 | через 35 дней |

Верный ответ поднимает на коробку выше, неверный сбрасывает в нулевую.
Дошло до пятой — слово считается выученным.

Интервалы заданы обычным списком в `kazvocab/srs.py`, менять их можно прямо там:

```python
INTERVALS = (0, 1, 3, 7, 16, 35)
```

## Как библиотека

```python
from kazvocab import load_deck, review, CardProgress, due_cards

deck = load_deck()
print(len(deck), deck.topics)

# что показать сегодня
keys = [c.key for c in deck.by_topic("food")]
print(due_cards({}, keys))

# применить ответ
p = review(CardProgress("су"), correct=True)
print(p.box, p.due)
```

### Основное

| Функция | Делает |
|---|---|
| `load_deck(path=None)` | читает колоду из JSON |
| `review(progress, correct)` | применяет ответ, возвращает новый прогресс |
| `due_cards(progress, keys)` | какие слова пора повторить, слабые первыми |
| `summary(progress, total)` | сводка: выучено, точность, повторений |
| `load_progress` / `save_progress` | чтение и запись истории |

`review` не меняет переданный объект, а возвращает новый — старое и новое
состояние можно сравнить.

## Своя колода

```json
{
  "name": "Моя колода",
  "cards": [
    { "kk": "су", "ru": "вода", "topic": "food" },
    { "kk": "нан", "ru": "хлеб", "topic": "food" }
  ]
}
```

```bash
python -m kazvocab.cli quiz --deck my_deck.json
```

Несколько переводов пишутся через запятую — `"девочка, дочь"` — и засчитывается
любой из них.

## Проверка ответов

Регистр и лишние пробелы игнорируются, `ё` приравнивается к `е`.

А вот казахские буквы **ә, ғ, қ, ң, ө, ұ, ү, һ, і** не подменяются:
`аке` вместо `әке` — ошибка. Различать их и есть смысл упражнения.

## Что не умеет

- нет озвучки — только письменная форма
- нет словоформ: слова даны в словарном виде, без падежей и аффиксов
- проверка посимвольная, опечатка засчитывается как ошибка
- прогресс лежит локально в `~/.kazvocab/progress.json`, между устройствами не синхронизируется
